Edition changes worth remembering

2nd edition: selected solutions, additional problems, Myhill–Nerode and Rice's theorem in solved material, repaired primality analysis.

3rd edition: major new section 2.4 on deterministic context-free languages, DPDAs, deterministic grammars, and LR(k) parsing.

Preserved: all major chapter topics remain in scope. Audit the differences and limitations.

Run the examples

cargo test or python -m unittest discover -s tests -v. All examples are intentionally small and independently authored.
